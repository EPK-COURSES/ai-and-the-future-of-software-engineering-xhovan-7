## Academic and Conference Papers

**[R1]** Pearce, H., Ahmad, B., Tan, B., Dolan-Gavitt, B., & Karri, R. (2022). Asleep at the Keyboard? Assessing the Security of GitHub Copilot's Code Contributions. *Proceedings of the 43rd IEEE Symposium on Security and Privacy (S&P 2022)*, 754–768.
IEEE. https://doi.org/10.1109/SP46214.2022.9833571
> This peer-reviewed paper directly examines the security of AI-generated code and provides quantitative findings used in Section 3.3 of this research.

**[R2]** Fraser, G., & Arcuri, A. (2011). EvoSuite: Automatic Test Suite Generation for Object-Oriented Software. *Proceedings of the 19th ACM SIGSOFT Symposium on the Foundations of Software Engineering (FSE 2011)*, 416–419.
ACM. https://doi.org/10.1145/2025113.2025179
> Foundational academic paper on EvoSuite, the evolutionary algorithm-based test generation tool discussed in Section 2.2.

**[R3]** Lemieux, C., Inala, J. P., Lahiri, S. K., & Sen, S. (2023). CodaMosa: Escaping Coverage Plateaus in Test Generation with Pre-Trained Large Language Models. *Proceedings of the 45th International Conference on Software Engineering (ICSE 2023)*.
IEEE. https://doi.org/10.1109/ICSE48619.2023.00085
> Examines how LLMs improve coverage in test generation tools — background for the discussion of AI-generated test reliability in Section 7.
